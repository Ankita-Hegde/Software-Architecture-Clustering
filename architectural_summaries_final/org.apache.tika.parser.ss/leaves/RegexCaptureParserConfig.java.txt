### Semantic Summary

#### Key Functionality
This Java class, `RegexCaptureParserConfig`, serves as a configuration object for the `RegexCaptureParser` class. It allows users to configure how the parser should operate by setting up mappings for capturing and matching regular expressions.

#### Core Logic
The core logic involves managing two maps (`captureMap` and `matchMap`) that store key-value pairs where keys are regular expression patterns and values are corresponding actions or identifiers. Additionally, it includes a boolean flag `writeContent` which determines whether the content should be written out during parsing.

#### Inputs/Outputs
- **Inputs**: 
  - `captureMap`: A map where keys are regular expression patterns and values are identifiers or actions.
  - `matchMap`: Another map where keys are regular expression patterns and values are identifiers or actions.
  - `writeContent`: A boolean value indicating whether to write the content during parsing.
  
- **Outputs**: None directly from this class. The outputs would be the parsed content based on the configurations set in `captureMap` and `matchMap`.

#### Dependencies
- This class depends on the `HashMap` class from the Java Collections Framework, which is used to store the `captureMap` and `matchMap`.
- It also indirectly depends on the `Serializable` interface, which allows instances of this class to be serialized (i.e., converted into a stream of bytes).

In essence, this class provides a way to configure a parser to recognize and act upon specific patterns within text using regular expressions.
