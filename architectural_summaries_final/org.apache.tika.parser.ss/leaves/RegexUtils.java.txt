### Semantic Summary

#### Key Functionality
The `RegexUtils` class provides a utility method to extract URLs from plain text using regular expressions.

#### Core Logic
1. **Pattern Definition**: Defines a regular expression (`LINKS_REGEX`) to match URLs in various formats.
2. **Pattern Compilation**: Compiles the regex pattern into a `Pattern` object for efficient matching.
3. **URL Extraction**: The `extractLinks` method uses the compiled pattern to find all matches in the given text and returns them as a list of strings.

#### Inputs/Outputs
- **Input**:
  - A `String` representing the plain text content from which URLs need to be extracted.
- **Output**:
  - A `List<String>` containing all the URLs found within the input text. If no URLs are found, an empty list is returned.
