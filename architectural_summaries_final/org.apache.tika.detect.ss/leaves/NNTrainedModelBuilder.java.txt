### Semantic Summary

#### Key Functionality
The `NNTrainedModelBuilder` class is designed to construct and configure a neural network model for document type detection using Apache Tika.

#### Core Logic
1. **Configuration**: The class allows setting various parameters such as the number of inputs, hidden layers, outputs, and model parameters.
2. **Building Model**: Once configured, it builds a `NNTrainedModel` object using the specified parameters.

#### Inputs/Outputs
- **Inputs**:
  - `MediaType`: Specifies the type of media the model will be used for.
  - `numOfInputs`: Number of input features for the model.
  - `numOfHidden`: Number of neurons in the hidden layer(s).
  - `numOfOutputs`: Number of output classes (e.g., different document types).
  - `params`: Array of floating-point numbers representing the model's parameters.
  
- **Outputs**:
  - A fully configured `NNTrainedModel` object that can be used for detecting document types based on input data.

#### Dependencies
- **org.apache.tika.mime.MediaType**: This class is used to specify the media type (e.g., text/plain, application/pdf) for which the model is being built.
- **org.apache.tika.detect.NNTrainedModel**: This is the class that represents the neural network model itself, which is instantiated and returned by the `build()` method.

In essence, this class provides a way to define and create a neural network model tailored for document type detection, encapsulating all necessary configuration details within its methods.
