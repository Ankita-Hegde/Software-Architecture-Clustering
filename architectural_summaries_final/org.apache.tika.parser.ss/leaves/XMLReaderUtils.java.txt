### Semantic Summary

#### Key Functionality
The `XMLReaderUtils` class provides utility methods for handling XML parsing in a secure and efficient manner. It focuses on creating and managing pools of XML parsers and DOM builders to optimize performance and resource usage.

#### Core Logic
1. **Pooling Mechanism**: The class maintains pools of `SAXParser` and `DocumentBuilder` instances to avoid repeated creation and destruction of these objects, which can be costly in terms of performance.
2. **Secure Configuration**: It configures parsers and builders to mitigate XML External Entity (XXE) attacks by disabling external entities and setting appropriate security properties.
3. **Reusability**: Parsers and builders are reused within their respective pools, and they are reset after each use to prepare them for the next parsing task.

#### Inputs/Outputs
- **Inputs**:
  - `InputStream`, `Reader`, `Path`, and `String` for parsing XML data.
  - `ParseContext` for storing and retrieving configuration settings.
- **Outputs**:
  - `Document` for DOM-based parsing results.
  - `XMLReader` and `SAXParser` for SAX-based parsing.
  - `Transformer` for transforming XML documents.

#### Dependencies
- **Java Standard Libraries**: Utilizes classes from `java.io`, `java.nio.file`, `java.util.concurrent`, and `javax.xml.*`.
- **Apache Commons IO**: For handling byte streams.
- **SLF4J**: For logging.
- **Apache Tika**: For parsing context management and content handling.
- **Xerces**: For XML parsing and security configurations.
- **Woodstox**: For StAX input factory configuration.

### Detailed Explanation

1. **Pooling Mechanism**:
   - **DOM Builders**: Managed by `DOM_BUILDERS` queue.
   - **SAX Parsers**: Managed by `SAX_PARSERS` queue.
   - **Resetting**: Each time a parser or builder is reused, it is reset to ensure it is in a clean state for the next use.

2. **Secure Configuration**:
   - **SAXParser**: Configured to disable external entities, set entity expansion limits, and apply secure processing features.
   - **DocumentBuilder**: Configured similarly to SAXParser but specifically for DOM-based parsing.
   - **StAX Input Factory**: Configured to disable external entities and set entity expansion limits.

3. **Reusability**:
   - **Acquiring Resources**: Methods like `acquireDOMBuilder()` and `acquireSAXParser()` allow acquiring resources from the pool.
   - **Releasing Resources**: Methods like `releaseDOMBuilder()` and `releaseParser()` return resources to the pool for reuse.

4. **Parsing Methods**:
   - **DOM Parsing**: Methods like `buildDOM()` and `parseSAX()` handle DOM and SAX parsing respectively, utilizing the pool for efficiency.
   - **Transformer**: Methods like `getTransformer()` manage the creation and configuration of transformers for XML transformations.

5. **Logging and Error Handling**:
   - **Logging**: Uses SLF4J for logging, with specific handlers for different types of errors and warnings.
   - **Error Handling**: Handles various exceptions and ensures that critical operations are logged appropriately.

This class is designed to provide a robust and secure framework for XML parsing, ensuring that common vulnerabilities like XXE are mitigated while optimizing performance through resource pooling.
