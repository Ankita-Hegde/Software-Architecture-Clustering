### Semantic Summary of the Provided Source Code

#### Key Functionality
The `StringUtils` class contains utility methods for string manipulation, including checking if strings are empty or blank, padding strings, repeating characters, and joining lists of strings.

#### Core Logic
1. **Checking for Empty or Blank Strings**: Methods like `isEmpty` and `isBlank` check if a string is null or empty.
2. **Padding Strings**: Methods such as `leftPad` add leading characters to a string until it reaches a specified length.
3. **Repeating Characters or Strings**: Methods like `repeat` create a new string by repeating a character or a string a specified number of times.
4. **Joining Strings**: The `joinWith` method concatenates a list of strings with a specified delimiter.

#### Inputs/Outputs
- **Inputs**:
  - `isEmpty`: Takes a `CharSequence` and returns a boolean indicating whether it's null or empty.
  - `isBlank`: Takes a `String` and returns a boolean indicating whether it's null or consists only of whitespace.
  - `leftPad`: Takes a `String`, an integer size, and a `String` or `char` for padding.
  - `repeat`: Takes a `char` or `String` and an integer repeat count.
  - `joinWith`: Takes a `String` delimiter and a `List<String>`.

- **Outputs**:
  - `isEmpty` and `isBlank`: Boolean values.
  - `leftPad`: A new padded `String`.
  - `repeat`: A new `String` with repeated characters or the original string.
  - `joinWith`: A single `String` that is the result of joining all elements in the list with the specified delimiter.
