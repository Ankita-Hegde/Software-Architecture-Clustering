The `TikaProgressTracker` class is designed to track the progress of parsing operations, particularly useful for monitoring the progress of long-running tasks like Optical Character Recognition (OCR) processes. It helps in detecting stalled parsers by periodically updating its internal state.

1. **Initialization**: The `TikaProgressTracker` is initialized with the current time when a new instance is created.
2. **Progress Updates**: Parsers can signal their progress by calling the `update()` method, which sets the current time as the last known progress update.
3. **Monitoring**: A monitoring loop can check the `lastProgressMillis` field to determine if a parser has made any progress within a certain timeframe.

- **Outputs**:
