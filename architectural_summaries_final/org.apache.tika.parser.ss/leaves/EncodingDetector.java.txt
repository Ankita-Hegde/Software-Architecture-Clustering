#### Key Functionality
The provided code defines an interface `EncodingDetector` which is part of the Apache Tika project. This interface is used to detect the character encoding of a text document. It leverages various heuristics based on the document's metadata and the initial bytes of the document.

#### Core Logic
1. **Detection Mechanism**: The core logic involves analyzing the input metadata and the first few bytes of the document to determine the character encoding.
2. **Ranking Results**: The method returns a list of `EncodingResult` objects, ranked in descending order of confidence. Each result includes a type (`DECLARATIVE`, `STRUCTURAL`, or `STATISTICAL`) indicating the nature of the evidence used to determine the encoding.
3. **Handling Input**: The method can accept a `TikaInputStream` (which supports marking and resetting) or `null` if the document input stream is not available. It also accepts metadata and a parse context as inputs.
