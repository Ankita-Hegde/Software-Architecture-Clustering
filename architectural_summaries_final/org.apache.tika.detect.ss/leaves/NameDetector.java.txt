#### Key Functionality
The `NameDetector` class is responsible for detecting the content type of a document based on its name. It uses a set of predefined regular expression patterns to match against the document's name, which can be a file name or a URL.

1. **Metadata Extraction**: The method `detect` retrieves the document name from the input metadata using the key `TikaCoreProperties.RESOURCE_NAME_KEY`.
2. **Name Processing**:

   - Strips leading and trailing slashes or backslashes.
   - Decodes any URL-encoded characters.
   - Trims any leading or trailing whitespace.
3. **Pattern Matching**: The cleaned-up name is then matched against a set of predefined regular expression patterns. If a match is found, the corresponding media type is returned. If no match is found, the default media type `application/octet-stream` is returned.
