### Semantic Summary

#### Key Functionality
The `MetadataFilterBase` class serves as a base implementation for filtering metadata objects in a list. It provides a framework for creating context-free metadata filters that can process each metadata object independently.

#### Core Logic
1. **Iteration**: The core logic involves iterating over a list of `Metadata` objects.
2. **Filtering**: For each metadata object in the list, it calls the `filter` method (which is abstract and needs to be implemented by subclasses).
3. **Error Handling**: If any error occurs during the filtering process, it throws a `TikaException`.

#### Inputs/Outputs
- **Inputs**:
  - A `List<Metadata>`: A list of metadata objects to be filtered.
  - A `ParseContext`: An optional context object that can be used to pass additional information to the filter.
  
- **Outputs**:
  - None directly; the filtering is done in place on the metadata objects.

#### Dependencies
- **Java Util Package**: Uses `java.util.List` for handling lists of metadata objects.
- **Apache Tika Libraries**: 
  - `org.apache.tika.exception.TikaException`: Used for throwing exceptions if something goes wrong during the filtering process.
  - `org.apache.tika.metadata.Metadata`: Represents a metadata object.
  - `org.apache.tika.parser.ParseContext`: An optional context object that can be passed to the filter.

This class is designed to be extended by other classes that implement the actual filtering logic, ensuring that the filtering process is applied to each metadata object in the list independently.
