### Title
Document Content Detection and Encoding Handling Module

### High-Level Descriptive Summary

The provided codebase forms a comprehensive module for detecting the content type and encoding of documents using various detection strategies and machine learning models. The module integrates multiple detectors, encoding detectors, and utilities to ensure robust and accurate content type and encoding identification. Here’s a detailed breakdown of the key components and their interactions:

1. **Content Type Detection**:
   - **Detectors**: The module includes multiple detectors such as `TextDetector`, `DefaultDetector`, and `ProbabilisticMimeDetectionSelector`. These detectors leverage different methods like magic bytes, file extensions, and metadata to determine the MIME type of a document.
   - **Composite Detector**: `CompositeDetector` combines multiple detectors to provide a more accurate and flexible content type detection mechanism. It supports dynamic exclusion of specific detectors and uses a `MediaTypeRegistry` to validate and prioritize detected types.
   - **Override Detector**: `OverrideDetector` allows for user or parser-specific overrides of detected content types based on metadata.

2. **Encoding Detection**:
   - **Encoding Detectors**: Classes like `OverrideEncodingDetector`, `CompositeEncodingDetector`, and `CharsetSupersets` handle character set detection and resolution. `OverrideEncodingDetector` allows overriding detected encodings, while `CompositeEncodingDetector` combines multiple encoding detection strategies.
   - **Charset Utilities**: `CharsetUtils` provides utilities for handling character sets, including checking support, cleaning up malformed names, and resolving common aliases.
   - **Bounded InputStream**: `BoundedInputStream` limits the amount of data read from an input stream, ensuring efficient handling of large files without loading the entire content into memory.

3. **Utility Classes**:
   - **StringUtils**: Provides utility methods for string manipulation, such as checking for emptiness, padding strings, repeating characters, and joining lists of strings.
   - **Property**: Manages metadata properties, particularly those used in XMP format, and supports composite properties.
   - **DetectHelper**: Provides utility methods for creating a `TikaInputStream` that can be used for content detection purposes, ensuring only a specified amount of data is read from an input stream.

4. **Machine Learning Models**:
   - **Trained Models**: `TrainedModel`, `NNTrainedModel`, and `NNTrainedModelBuilder` form the foundation for implementing machine learning models. `NNTrainedModel` processes input data through a neural network to produce predictions, while `NNTrainedModelBuilder` constructs and configures neural network models.
   - **Example Model Detector**: `NNExampleModelDetector` utilizes pre-trained neural network models for media type detection, extending `TrainedModelDetector` to load and utilize these models.

5. **XML Handling**:
   - **XmlRootExtractor**: Extracts the root element's namespace URI and local name from an XML file, handling cases where the XML might be malformed or truncated.

6. **Text Statistics**:
   - **TextStatistics**: Analyzes a stream of bytes to determine if the content is likely to be plain text or UTF-8 encoded text, providing statistics on byte frequencies and character distributions.

By integrating these components, the module offers a robust framework for accurately detecting and handling document content types and encodings, making it suitable for a wide range of applications in document processing and analysis.
